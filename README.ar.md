لعبة استراتيجية في الوقت الحقيقي بطابع خيالي، **مفتوحة المصدر** وقابلة للعب في المتصفح،
فيها قرويون بأسماء، ونقابات، وبناء، وموارد، وأسوار، وقتال، وأوامر باللغة الإسبانية.

يقتصر النطاق الحالي على المعارك والمناوشات ضد الذكاء الاصطناعي، مع الاقتصاد
والبناء والقتال على خرائط مكشوفة. ولا يتضمن حملات.

![Gremios del Alba](assets/hero.png)

## اللعب محليًا

المتطلبات: **Node.js 24 أو أحدث** ومتصفح حديث. لا توجد اعتماديات npm
تحتاج إلى تثبيتها.

<div dir="ltr">

```sh
git clone https://github.com/Oruga420/gremios-del-alba.git
cd gremios-del-alba
npm start
```

</div>

افتح **http://127.0.0.1:4173**. وعلى Windows يمكنك أيضًا استخدام `PLAY.cmd`.
صُمّم الخادم للاستخدام المحلي ويستمع على واجهة loopback.

## ما الذي تتضمنه

- عشر خرائط مكشوفة بالكامل وأربع نقابات أصلية.
- الجمع والنقل والإيداع؛ يبحث القرويون عن موارد يمكن بلوغها
  عند نفادها، ويحتفظون بالحمولة إذا لم يتوفر مخزن.
- البناء والإصلاح والأسوار والبوابات.
- تشكيلات الخط والمربع والمتدرج، مع وجهات فردية ومسارات
  مشتركة. ويبقى الاختيار محفوظًا عند تحريك المجموعة.
- نقاط تجمع على الموارد والبساتين: يبدأ العمال الجدد بالجمع
  فور خروجهم من المبنى.
- التجنيد والتقنيات والعصور والتجارة، وحد أقصى قدره 1,000 ساكن لكل مدينة.
- فرسان ورماة وقتلة وسحرة ومعالجون وأدوار أخرى؛ ورسوم متحركة
  للقتال والدماء والجثث.
- الحفظ والتحميل بصيغة JSON، والتحديد بالسحب، والمجموعات، والخريطة المصغرة.
- محلل أوامر باللغة الإسبانية وأدوات صفحة WebMCP.
- وكيل صوتي اختياري بحساب المستخدم نفسه وبيانات اعتماده.

حدد الوحدات بالسحب، وانقر بالزر الأيمن لإصدار أمر. استخدم
البطاقات السفلية للبناء أو التدريب، ومفتاح المسافة للإيقاف المؤقت.
وتحتوي مساعدة اللعبة على مزيد من عناصر التحكم. وعند تحديد عدة وحدات،
استخدم الأزرار **خط** و**مربع** و**متدرج** لإعادة تجميعها. حدد
مبنى منتجًا وانقر بالزر الأيمن على مورد لإرسال عماله الجدد
إليه. وتعرض لوحة التحديد حمولتهم وما إذا كانوا يجمعون أو
يودِعون أو ينتظرون موردًا أو مخزنًا يمكن بلوغه.

تكرار أمر الجمع على المورد نفسه يحافظ على المهمة
والمسار والحمولة. وأثناء التقدم الهجومي، تستأنف الوحدات طريقها إلى وجهتها
إذا لم تستطع بلوغ عدو اكتُشف تلقائيًا. أما الهجوم
الصريح فيحافظ على الهدف الذي اخترته.

## الصوت وWebMCP

تعمل الأوامر المكتوبة واللعبة دون مفاتيح API. ويعتمد التعرف على الصوت
في المتصفح على توافقه وأذوناته. أمثلة على الأوامر:
**«ابنِ بيتًا»**، و**«القرويون، اجمعوا الخشب»**، و**«اصطفوا في خط»**،
و**«تشكيل متدرج»**، و**«حرك الرماة في مربع إلى قاعدتي»**،
و**«نقطة التجمع من دار النقابة إلى الغابة»**. وتُحدَّد الوجهات
وفق العالم الحالي. تُنفَّذ الأوامر فورًا، دون تأكيد
ولا حاجة إلى إحداثيات؛ و**«توقف»** يوقف الوحدات.

للوكيل الحواري، أنشئ Agent خاصًا بك على ElevenLabs
وانسخ `.env.example` إلى `.env`. عرّف `ELEVENLABS_API_KEY`
و`ELEVENLABS_AGENT_ID`، ثم أعد تشغيل الخادم. يبقى المفتاح على
الخادم. استخدام المزوّد اختياري وقد تترتب عليه تكلفة في حسابك.
يصدّر `npm run voice:definition` محليًا تعريفًا يتضمن أدوات
اللعبة؛ اختر صوتك ونموذجك لدى المزوّد أو عبر خيارات
المثال. لا يُنشأ أي وكيل ولا تُجرى أي مكالمة بمجرد تثبيت اللعبة.

التعرف دون اتصال اختياري ويتطلب Python وVosk وFFmpeg
ونموذجًا للغة الإسبانية. اضبط `GUILD_PYTHON_PATH` و`GUILD_FFMPEG_PATH`
و`GUILD_VOSK_MODEL_PATH`. لا تُضمَّن نماذج ولا تسجيلات.

يشغّل `PLAY-WEBMCP.cmd` متصفح Chrome متوافقًا مع خيار WebMCP وملفًا شخصيًا
محليًا مخصصًا. وتُبلغ اللعبة عن القدرة المتاحة فعليًا. ولهذا الملف الشخصي
حفظه الخاص: استخدم تصدير JSON واستيراده لنقل مباراة.

## التطوير والاختبارات

<div dir="ltr">

```sh
npm test
npm run check
npm run build
```

</div>

يحتوي `dist/` على العميل الثابت المُولَّد. ويتضمن الخادم المحلي
مسارات الصوت والتعرف دون اتصال؛ وعلى Vercel، يخدم `api/guild.mjs`
مسارات Sota دون الاعتماد على حاسوب قيد التشغيل. وقائمة
الأدوات موجودة في `docs/voice/clickables.json`؛ وعقد المحرك موجود
في `docs/engine-interface.md`.

### النشر على Vercel

استورد هذا المستودع مع Node 24 واحتفظ بـ`vercel.json`. يُبنى العميل
في `dist/`؛ وتعمل المسارات `/api/*` كدالة Node دون
اعتماديات إضافية. تُحفظ المباريات في متصفحك أو تُصدَّر
بصيغة JSON. ويبقى التعرف دون اتصال عبر Vosk متاحًا في النسخة المحلية؛
أما في رابط Vercel العام فاستخدم صوت المتصفح أو اكتب الأوامر.

فعّل **Vercel Authentication → Standard Protection** في المشروع. يسمح
نطاق الإنتاج باللعب دون تسجيل الدخول. وتبقى العناوين الفريدة
للنشر خاصة: لا يُصدر Sota الشخصي تفويضات إلا من
المضيف المحمي الذي تقدّمه Vercel في `VERCEL_URL`. ويتاح صوت المتصفح
والأوامر المكتوبة في اللعبة العامة. عرّف بوصفها متغيرات
إنتاج مشفرة `ELEVENLABS_API_KEY` و`ELEVENLABS_AGENT_ID`
و`GUILD_PUBLIC_ORIGIN` (أصل HTTPS الدقيق) و`GUILD_SESSION_SECRET` (عشوائي،
32 حرفًا على الأقل) و`GUILD_DEPLOYMENT_PROTECTION=vercel-auth`.
لا تضع قيمها في GitHub. يصرّح المؤشر بالحماية المضبوطة؛
لكنه لا يحل محل التحكم في الوصول لدى Vercel. لا تعطّل حماية
العناوين الفريدة إذا فعّلت الوكيل المدفوع. ولا يُصدر النطاق العام أبدًا
تفويضات ElevenLabs، حتى لو كانت لديه جلسة ورمز CSRF صالحان.

تستخدم الجلسة وCSRF ملف تعريف ارتباط موقّعًا بخصائص HttpOnly وSecure وSameSite.
وحدود الإصدار والمكالمات المتزامنة محسوبة لكل نسخة من الدالة؛
ولا تعادل حصة عامة ولا حدًا للفوترة. أبقِ
الوصول الخاص محميًا واضبط حدود الاستخدام لدى مزوّدك. وتنتهي مكالمة
العميل بعد خمس دقائق أو بعد 90 ثانية من الخمول.

هناك اختبارا أداء اختياريان مدة كل منهما 120 ثانية. شغّلهما
كلًّا على حدة كي لا يختلط حملهما:

<div dir="ltr">

```sh
npm run benchmark
node scripts/benchmark-formations.mjs
```

</div>

يحافظ الأول على سيناريو القتال والاقتصاد مع 1,000 ساكن
لكل مدينة؛ ويختبر الثاني التشكيلات الثلاثة مع اقتصاد نشط.
وتصف التقارير المحلية المُولَّدة السيناريو والقياسات وحدودها؛
ولا تُضمَّن نتائج خاصة ولا يُفترض الأداء
على جهاز آخر.

تتطلب اختبارات المتصفح تثبيت Playwright ومتصفحه
بشكل منفصل؛ وهي ليست اعتمادية للعب. وهناك اختبارات انحدار بلغة Python لأداة الاختبار،
ومشغّل في `scripts/run-browser-acceptance.py`.

## حالة المشروع

إنه نموذج أولي قيد التطوير. الفصل المحلي أثناء الحركة
تقريبي ويسمح بالتداخل؛ وما زال الاستيفاء المرئي
وتحسينات السلوك في المواقف المزدحمة قيد الانتظار. ويعتمد الأداء مع الأحمال
الكبيرة على السيناريو والعتاد. وقد أظهرت أداة اختبار المتصفح الكاملة
مشكلات في إغلاق Chrome/Playwright؛ والفحص الجزئي
لا يعادل اختبار E2E كاملًا.

الحركة والتشكيلات والجمع تطبيقات أصلية خاصة بالمشروع. وما زال
البحث المرجعي باستخدام REA جزئيًا: إذ لم يستعد
الخوارزميات الدقيقة للملاحة أو التشكيل أو الجمع في Age of Empires.
ولا يُدّعى التكافؤ مع محركها.

يحتوي هذا المستودع على شيفرة أصلية وموارد مُولَّدة. ولا يحتوي على
محرك تجاري مُستعاد، ولا ملفات من Age of Empires، ولا بيانات حسابات،
ولا سجل تطوير خاص، ولا مفاتيح مشتركة.
